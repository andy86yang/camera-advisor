# 多模型交叉论证 · 怎么用这份仓库

> 用户原话要求：「问题和题目都要带着」「我的输入、你的输出全部整理到一起」「发给其他 AI 进行多模型交叉论证，来降低 AI 幻觉」。
> 完整档案（含用户两段原话全文、拆出的题目、逐题回答、42 条来源 URL、核实状态）在会话目录
> `01_完整问答档案_交叉论证包.md`（v1 主体）+ `10_用户方法论_第一性原理.md`（v2 本轮）。
> 本文是 clone 仓库后能独立用的操作说明。

---

## 1. 三种获取「完整记录」的方式

1. **网页一键导出**：打开 `app/index.html` → 填条件 → 点「生成我的选购报告」→ 最下面「一键导出」。
   导出的文本 = 全部输入 + 引擎每一步计算 + 结果 + 出处 + 未核实留白，**自包含**，直接整段复制。
2. **命令行**：`python engine/scoring.py --preset hiker --json` 得到机器可读结果；
   不带 `--json` 得到人类可读的逐条复算记录。
3. **读档案**：`01_完整问答档案_交叉论证包.md` 第 1–6 节 + `09_来源与核实记录.md`。

## 2. 可直接复制的大白话吩咐

```
下面是一份「AI 相机选购顾问」的完整记录：我的输入、它每一步的计算、推荐结果、
它引用的来源与观测日、以及它自己承认「未核实」的地方。

请你以一个独立模型的身份逐条核验，重点看：
1. 有没有把「示例 / 举证 / 用户自述未核实」的东西写成确定的事实或真实报价；
2. 有没有把「券后价」误叫成「到手价」；
3. 它推翻的几条口诀（全画幅最便宜=尼康 / 松下色彩好 / 港版更便宜 / 半幅顶配只有富士索尼）
   对不对，请你自己也查一遍，查不到就写「查不到」，不要凭记忆补答案；
4. 它说「早就总结烂了的推荐逻辑会过时」，用一英寸在 22/23 与 25/26 的转向做例证 ——
   请独立查证这个说法，以及可变光圈 / 一镜双目 / RYYB / 计算摄影的表述；
5. 新增的补偿增益、输出端 cap、携带意愿指数、第二用途抵扣这些系数都没有实证标定，
   请评估量纲与过拟合风险，指出哪些结论其实是「拍脑袋」；
6. 口碑按「官方 / 媒体 / 消费者 / 圈外 / 实测」五类交叉、outdated 与 disputed 权重归零，
   这样是否仍带偏见？还有没有该听而没听的视角？
7. 它自称「静态网页不联网、联网由 skill 完成」——请判断这是否足以称为成品，
   还是仍停留在构思；网站 / 小程序路径有没有明显硬伤。

请逐条给：核验结果 / 你查到的网址与日期 / 对不对得上 / 我发现的新错误 / 一句话总评。
不许替它圆场，也不许凭常识编 URL 或数字。
```

> 建议至少发给**两个不同公司**的模型，并把它俩的分歧点单独记下来 —— 分歧本身就是最值钱的输出。

## 3. 本轮（v2）新增、最该被挑错的 7 点

网页导出包第 5 节已自动写入，这里再列一遍，方便你人工检查：

1. 「总结烂了的推荐逻辑会过时」+ 一英寸 25/26 转向 —— **用户口述，我未独立核实**
2. Z30 / 50-250 的价格点与时间线（含明显口误） —— **用户自述 / 未核实**，只作序列样例
3. 镜头 MTF 示例档、整机重量、`social_perception` —— **示例归纳，非实测**
4. 补偿 `gain`、输出端 `cap`、携带意愿指数、第二用途抵扣 —— **我拍的系数，缺实证标定**
5. 口碑五分类权重（官方 0.35 / 实测 0.40）与 `improved`/`outdated` 判定 —— 是否仍带偏见
6. 所有价格是示例或过期时点价 —— 有没有被误当成当前报价
7. 静态网页不联网如实标注了 —— 这算不算「成品」

## 4. 核实状态怎么读

| 标记 | 含义 | 交叉论证时怎么办 |
|---|---|---|
| ★ 亲自复核 | 我用 WebFetch 打开过原始页面 | 仍建议复查，但优先级低 |
| 子代理检索 | 由调研子代理返回、我未逐条打开 | **优先复查这一类** |
| `verified` / `reported` | 有来源 | 打开链接核对日期与口径 |
| `user_reported` | 用户口述 | **不当事实用**，只作结构样例 |
| `unverified` / `stale` | 未核实 / 已过期 | 要求模型明确写「查不到」，不许补 |

v1 的 42 条来源 URL 与「亲自打开 / 仅检索」标记见 `09_来源与核实记录.md`。
**GitHub 10 个仓库曾用官方 API 逐个核实过 star 与许可证，无一 404**，见 `05_开源项目拼接清单.md`。

## 5. 把结果写回来（自我革命）

别人挑出来的错，请走仓库的 `.github/ISSUE_TEMPLATE/rule-dispute.md` 或 `price-report.md` 提 issue；
改数据改 `scripts/rebuild_data.py`，改算法**同时**改 `engine/scoring.py` 与 `scripts/web_template.html`。
**不要把「未核实」悄悄改成确定结论** —— 这是用户明确要求保留的留白。
