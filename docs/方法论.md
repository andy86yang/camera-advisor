## 0. v1 错在哪

| v1 的说法 | 修正 |
|---|---|
| 「推荐逻辑，博主早就总结烂了」 | **错**。一英寸在 22/23 是共识，25/26 手机纷纷选略小底 + 可变光圈 / 一镜双目 / RYYB / 计算摄影换动态范围与帧率。结论有**适用条件和时效**。可复用的是**失效条件 + 复核机制**，不是结论 |
| 主线放在「核查并推翻 4 条口诀」 | 核查降级为知识库维护动作；主线是「输入一个人 → 输出适配他的方案」 |
| 「AI 不收广告就没偏见不成立」 | 只下否定判决、没给工程路径。客观性是可**工程逼近的程度**：多元来源 / 利益标注 / 时间戳 / 可调权重 / 小白代判 / 可导出 |
| 一堆 md + 8 项问卷网页 | 用户原话「不成系统」「比较牛逼点的 Word」「不是一个软件」「构思多、实践少」。→ v2 做成引擎 + 成品界面 + 可 clone 仓库 + 联网 skill |

**一句话**：v1 算「哪台机器参数好」，v2 算「**这个人在他真实的约束下，哪套方案最值、最愿意用、最不后悔**」。

## 1. 十一条原理（P1–P11）

| # | 原理 | 口述锚点 | 代码位置 |
|---|---|---|---|
| P1 | **起点是现有装备 + 现有能力 + 真实约束**，不是品牌口诀 | 小米 13 Pro 一英寸、长焦弱、微距可；爬山要广角、像素不够；现有手段是 RAW+锐化+超分+调色；但麻烦、上限低、**手机电量还要导航/上传/付费** | `q.current_gear / pains / constraints`，画像里判断「要不要加独立设备」 |
| P2 | 预算约束的是**整套系统**（机身+镜头+配件） | 一万预算买全幅机身就没钱买头 | `M1` 硬过滤，不满足直接淘汰/改推过渡方案 |
| P3 | 预算不够时选**过渡机 / 老机身**，保留升级路径 | 选「出了很多年、不会再降太多」的 Z30+16-50 | `role: transitional` |
| P4 | 价格是**时间序列**，没有「跌到底」，降幅也不挑大促 | 25-11 3006 买 Z30，26 双 11 约 3000；50-250 从 1700/1800 降到 1395/1400 发生在 7/8 月，双 11 双 12 反而没变化；一年亏约 1000，但「冲首发亏更多」 | `price_history.json` + 每日采样 workflow + `M6` 折旧 / 首发溢价 / 相对参照系 |
| P5 | **短板可被低成本/零成本手段补偿**（田忌赛马核心） | RAW 不拍 JPG、锁 ISO 100、向右曝光、F1.7/F1.2（不用 2.8/1.8）、快门 1/200→1/120→1/80、补常亮灯/手电筒、PS 降噪+超分，后期 10–20 分钟 | `M2b` `compensations`：裸分 → **有效分**，增益 − 时间/器材代价 |
| P6 | **收益由输出端决定**；边际效应递减 | 10MB/20MB 发朋友圈都 100 多 KB；4K60 vs 1080P60 在 1080P 屏上不明显，都是 60 帧，LUT 讨喜反而更赢；「成本 +80%、效果 +8%」 | `M3` `output_caps` 超 cap 折损 + `M5` 分/千元 |
| P7 | **愿意带出去**是一票级指标；人体工学与健康 | 爬山十几二十公里，塑料机身镜头轻才愿意拿；金属合金就不愿意；用多了手会得筋膜炎；个子高→三脚架要大，手小劲儿小→轻便 | `M4` 重量→出勤率**乘性因子** + 负重一票否决 + `ergonomics_profile` |
| P8 | **退居二线 = 消除沉没成本** | Z30 是 vlog 机 / 直播副机位；别人出二手会亏，「我退居二线，不存在这个经济损失」 | `M6` 持有成本 − `secondary_uses` 抵扣 |
| P9 | **反经验主义**：口碑带时间戳，知识库能自我革命 | 华为/小米/OPPO/vivo 曾有问题但日新月异；「曾经犯过错 ≠ 现在还在错」；「要不断自我革命、活到老学到老」 | `reputation.json` 的 `as_of/status/review_due`，`outdated`/`disputed` 权重 0，`improved` 低权重；每周复核 workflow + 质疑 issue 模板 |
| P10 | **来源多元 + 官方不可全信 + 社交是真实需求** | 官方王婆卖瓜；媒体/主播受品牌方、广告商、二手商驱动（卖二手的必推二手且不说磕碰/快门/质保）；品牌教育用户有产品周期；光看圈内是自嗨，得听圈外；马斯洛除自我认同还有社交（奔驰 C 被鄙视）；**小白不认识圈内大佬** | `source_types` 五类 + bias；`social` 用户可调；`novice_mode` 由 AI 代判可信度 |
| P11 | **主次矛盾 / 不做全才 / 信息密度适配** | 滴滴司机该学省电、何时充电省钱、不顿挫让乘客不吐，不必懂发电机历史与第二次工业革命；出租车报尾号直接说 3149，打哑谜是效率低、**场景错配** | `M8` 画像分「主要矛盾 / 次要矛盾 / 不必纠结」；`expertise` 决定解释深度 |

## 2. 决策链

```
P1 现有装备 + 痛点 + 稀缺资源 → 先问「要不要加设备」
  ↓
P2 整套预算可行性 ── 不满足 → P3 过渡机
  ↓
P4 价格时间序列（每日采样，别只盯大促）
  ↓
P5 短板补偿（有效分） + P6 输出端天花板（边际递减） = 田忌赛马
  ↓
P7 愿意带出去（乘性出勤率 + 人体工学 + 一票否决）
  ↓
P8 持有成本（折旧 + 二手折价 − 第二用途抵扣）
  ↓
P9 口碑时间戳（过期降权 / 已改善） + P10 多元来源 / 社交 / 小白代判
  ↓
P11 按主次矛盾输出画像（不做全才）
```

## 3. 「AI 能不能尽量客观」——工程方案而非判决

客观性不是「有 / 没有偏见」的开关，是可逼近的程度：
① 每条结论标 `来源类型 + 利益关系 + 观测日 + 核实状态`；
② **官方 / 权威媒体 / 消费者使用者 / 圈外 / 可复现实测** 五类交叉，任何一类不独占；
③ 口碑带 `as_of`，过期自动降权，「曾经有问题」≠「现在还有问题」；
④ 社交认同作为**用户可调**显式维度，不偷偷塞进品牌分；
⑤ 小白模式下可信度由 **AI 代判**，界面不暴露权威加权表；
⑥ 全流程可导出、可交给第二个模型挑错。

## 4. 不写进库的部分

口述里用于举例的**具体个人、婚恋私事、对具体 UP 主的水平褒贬**一律不采集、不核实、不写入数据文件、不在界面展示。
可泛化的部分已抽成 P9（名气 ≠ 专业度、口碑带时间戳）、P10（利益标注）、P11（语境适配 / 效率 / 错配）三条机制。
