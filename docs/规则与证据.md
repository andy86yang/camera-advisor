# 规则与证据（仓库自包含版）

> 完整版见会话目录 `04_选购知识库_规则与证据.md` 与 `09_来源与核实记录.md`。
> 权威规则文件是 `data/rules.json`；本文只解释怎么读、怎么改。

## 1. 两套分级，别混

**按「硬不硬」分（v1 就有，决定权重上限）**

| 等级 | 含义 | 能否单独决定推荐 |
|---|---|---|
| A | 可量化硬指标 / 厂商规格 | ✅ |
| B | 厂商一手 / 官方条款 / 官方访谈 | ✅，但标明是厂商说法 |
| C | ≥2 个独立来源共识 | ⚠️ 中等权重 |
| D | 主观审美 / 口碑 | ❌ 权重 ≤ 0.05 |
| E | 未核实 / 冲突 | ❌ 不入库 |

同一篇被多站转载只算 **1 个来源**。

**按「谁说的、有什么利益」分（v2 新增，P10）**

| 类型 | 默认权重 | 必须标注的 bias |
|---|---|---|
| `official` 品牌官方 | 0.35 | 王婆卖瓜，只列优点、隐藏缺点；占比可高但不可全信 |
| `media` 权威媒体 / 头部主播 | 0.20 | 可能受品牌方、广告商、二手商驱动；敌对媒体放大缺点；**名气 ≠ 专业度** |
| `consumer` 消费者 / 实际使用者 | 0.25 | 样本偏个人；能补官方盲区（品牌教育用户有产品周期，设计有的过于超前有的过于落后） |
| `outsider` 圈外视角 | 0.10 | 不懂术语，但反映社交观感与真实门槛；只看圈内 = 圈内自嗨 |
| `measured` 可复现实测 / 硬规格 | 0.40 | 测量条件差异 |

⚠️ 两套分级**不能互相替代**：一条 A 级规格若是厂商自述，仍要标 `official`；一条消费者长文即使只有 D 级，也是独立的视角。

## 2. 口碑状态机（P9）

`data/reputation.json` 每条带 `as_of / status / source_type / bias / review_due / weight`。

| status | 含义 | 权重 |
|---|---|---|
| `current` | 现行 | 按 weight |
| `improved` | **历史问题已改善** | ≤ 0.05，禁止照抄旧标签 |
| `outdated` | 已被现实推翻 | **必须 0** |
| `disputed` | 查不到 / 来源打架 | **必须 0** |

「曾经犯过错误」≠「现在还在错」。要质疑、要打疑问，但不能全盘否定 —— 这是用户明确批评的经验主义 / 教条主义。
`engine/scoring.py --validate` 会强制检查 `outdated`/`disputed` 权重为 0。

## 4. 品牌加分（只加分，不判决）

`rules.json → brand_bonus` 5 条，`requires` 全部满足才生效，权重 0.15–0.25，且按证据等级封顶。
例：`R01 Canon +0.15` 需要「直出 JPEG 不修图 + 拍人」，条件一变就不加分。
**不写「拍人 → 佳能」**。`banned_rules` 已删除被推翻的口诀。

## 5. v2 新增的可计算规则

| 键 | 内容 |
|---|---|
| `compensations` | 三类短板（动态范围 / 高感噪点 / 总进光量）× 手段（RAW、ETTR、锁 ISO100、AI 降噪、超分、F1.7·F1.2、慢快门、补灯）× `gain / cost_min / cost_money / requires` |
| `output_caps` | 6 种输出端（朋友圈 / 抖音 / 小红书 / B站4K / 打印 / 商业交付）× 属性 cap × `over_cap_penalty` |
| `weight_policy` | `limit_at_20km_g=700`、`carry_exponent=0.9`、`hard_veto_total_g=900`、**整套重量按该卡口最轻可配镜头算** |
| `ergonomics_profile` | 身高 ≥180 → 三脚架 ≥160cm；手小/劲儿小 → ≤550g；筋膜炎 → 负重上限 −15% |
| `secondary_use_offset` | 每个第二用途抵扣 0.06 × 整套价，上限 0.18 |
| `social` | 默认 0.15，可调 0–0.6；`novice_mode` 由 AI 代判可信度 |
| `source_types` | 五类来源定义见上 |

⚠️ **以上所有系数都是示例标定、未经实证**，界面与导出包均如实标注。改系数请走 `CONTRIBUTING.md` 第 7 节并给实测依据。

## 6. 明令禁止（`banned_rules`）

- 任何品牌 / 口碑规则不带 `as_of` 与 `status` → 违反 P9
- 把「曾经有过问题」直接写成「现在不行」→ 经验主义，应标 `improved` / 待复核
- 只在大促抓价 → 违反 P4
- 用裸参数直接加权、不考虑补偿与输出端 cap → 等同照抄博主公式
- 把重量当普通加性小分 → 必须是乘性出勤率因子
- 把社交认同偷偷塞进品牌加分 → 必须是用户可调显式维度
- 国补一律 15% → 口径冲突，禁止硬编码
- 全幅最便宜=尼康 / 松下色彩好 / 港版更便宜 / 半幅顶配只有富士索尼 → 均已作废
