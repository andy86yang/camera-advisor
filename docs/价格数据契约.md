# 价格数据契约（仓库自包含版）

> 完整版见会话目录 `03_价格数据契约.md`。核心结论：**「到手价」不是一个能查到的数字，是一道算式。**

## 1. 四元组（缺一即 `unverified`，不许显示成「到手价」）

| 字段 | 说明 |
|---|---|
| `region` | 地域（省 / 国家）。国补按省、渠道价按地域 |
| `observed_at` | 观测日 `YYYY-MM-DD`。超过 `stale_after_days = 7` 降级为 stale |
| `price_type` | 见下，七选一 |
| `condition` | 全新 / 二手成色等级 + 快门数 + 保修状态 |

外加 `origin`（能点开的原始页面）、`confidence`（`verified / reported / user_reported / unverified`）。

## 2. 七种价格类型

`msrp` 官方建议零售价 ｜ `list_price` 挂牌价 ｜ `coupon_price` 券后价 ｜
**`final_price` 到手价（实付）** ｜ `used_ask` 二手要价 ｜ `used_sold` 二手成交价 ｜ `trade_in_quote` 以旧换新报价

> ⚠️ **券后价 ≠ 到手价**。`fetch_prices.py --self-test` 会主动拒绝把 `coupon_price` 当到手价。

## 3. 到手价算式

```
挂牌价
− 平台 / 店铺券
− 满减
− 会员折扣
− 国补            ← 走资格判定，禁止硬编码 15%
− 直播间券
− 以旧换新
+ 运费
− 晒单返卡
= 实付到手价
```

同一个人同一台机，换个省份、没国补资格、没旧机置换、不是会员，实付就变。
所以软件不该「查一个价」，该**按用户填的条件算一个价**，并把每行扣减摊开。

**国补口径冲突（2026-11-25 未调和）**：有来源说 15% 国补可用，另有来源说单价超 6000 元不参与。
本系统**禁止硬编码 15%**，走资格判定并让用户自己确认；v1 已在 `prices.json` 的 `subsidy_note` 里标「口径待核实」。

## 4. 港版 / 二手

- **港版**：不加分、不参与国补、强制提示保修风险。
  佳能中国官网三包条款「但仅限于在中国大陆地区购买的产品」：
  `https://m.canon.com.cn/supports/policy/5364.html`（2026-11-25 亲自复核）。
  「港版一定更便宜」已判 `outdated`：厂商税后统一价 + 国补只给国行，常常国行到手更低。
- **二手**：必须带成色等级 + 快门数 + 保修状态；运费单列；不参与国补。
  卖二手的人推荐二手时未必会告诉你磕碰、划痕、机械快门寿命与质保影响 —— 这是 `source_type=media` 的 bias 标注来源。

## 5. 价格是时间序列，不是大促快照（P4）

用户口述：**50-250 从 1700/1800 降到 1395/1400 发生在 7/8 月，双 11 双 12 反而没什么变化**；
Z30 套机一年从 3006 到约 3000，老机型仍在缓降，不存在「跌到底」。

因此：
- `.github/workflows/update-prices.yml` **每日**采样（不是只在 618 / 双 11 跑）
- `price_history.json` **只追加、不覆盖**，Git 天然留下完整价格曲线
- 记录 `first_launch_price` 基线 → 算**首发溢价**
- 亏损同时给「绝对折旧」与「**相对参照系**」（冲首发的人亏更多，所以「不算十分肉疼」）
- 软件本体读 `prices.json`，**改价 = 换一张纸，代码一行不动**

## 6. 数据源清单（2026-11-25 检索状态，接入前必须重新核实）

| 来源 | 官方 API | 主要注意 | 二手 | 港版 |
|---|---|---|---|---|
| 京东商品页 / 京东联盟 | 联盟 API 需资质 | 商品页反爬；联盟有准入与调用规范 | 否 | 否 |
| 什么值得买 | 未核实 | 多为爆料价，时点/地域/券条件常缺，需人工核四元组 | 否 | 是 |
| 慢慢买 / 历史价格 | 未核实 | 历史曲线可用，口径与到手价不一定一致 | 否 | 否 |
| 闲鱼 | 未核实 | 需登录、反爬强；成色/快门/保修需归一化 | 是 | 是 |
| MPB / KEH | 未核实 | 海外二手，成色分级规范；汇率/运费/关税/地域 | 是 | 否 |
| B&H / Amazon | 部分联盟 API | 海外 MSRP 为主，**禁止直接换算成国内到手价** | 否 | 否 |
| Camera Price Compare / Google Shopping | 未核实 | 聚合口径，需回溯原始商家页 | 否 | 否 |

## 7. 硬规矩

- `scripts/fetch_prices.py` **当前未接任何真实源**，只有适配器接口 + 四元组校验 + `--dry-run`。
  接入前确认 robots / 服务条款、是否需要登录或 cookie、反爬与合规风险、更新频率、是否覆盖二手与港版。
- **任何分支都不许让模型生成一个价格。** 抓不到就显示「价格未核实 / 已过期，请自行核对」。
- 本仓库所有价格均为示例 / 举证 / 用户自述未核实，**禁止用于下单**。
